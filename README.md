## About

Vegas Fire Dancers is a free, weekly community gathering for fire performers and flow artists of all skill levels. We meet every Sunday night in Las Vegas, NV to spin, learn, and grow together — always with safety as our top priority.

## 🌐 Website

This repository hosts the Vegas Fire Dancers website via **GitHub Pages**.

### Quick Deploy

1. Fork or clone this repository
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch** → `main` → `/ (root)`
4. Your site will be live at `https://yourusername.github.io/vegas-fire-dancers/`

### Custom Domain (Optional)

1. Purchase a domain (e.g., `vegasfiredancers.com`)
2. Add a `CNAME` file to the repo root containing your domain
3. Configure DNS:
   - `A` records pointing to GitHub Pages IPs (185.199.108-111.153)
   - `CNAME` record for `www` pointing to `yourusername.github.io`
4. Enable HTTPS in Settings → Pages

## 🔒 Safety First

Every jam in Las Vegas, NV includes:
- Trained safety spotters with fire blankets and extinguishers
- Designated fuel station away from spin zone
- First aid supplies including burn care
- Mandatory safety briefing for new attendees
- Zero-tolerance policy for alcohol while spinning
